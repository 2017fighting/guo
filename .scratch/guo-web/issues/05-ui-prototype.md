# 核心页面交互原型

Status: open
Type: prototype
Blocked by: 01

## Question

用 frontend-mockup-loop 技能（system: shadcn，React + Tailwind + 官方 shadcn/ui 方向）做核心页面可点原型：

- 浏览（海报墙 + 筛选/排序）
- 搜索（联想 + 结果页）
- 详情（资料 + 选集 + 下载入口）
- 播放页（hls.js 播放器 + 弹幕开关 + 选集）
- 下载队列页（进度/暂停/重试/删除）

数据面以 `docs/research/hongguo-protocol.md` 结果为准（字段、筛选维度、画质档位）。用户对原型逐页拍板后，形成各页交互规格，作为「实现规格汇编收图」的输入。
